## แนวทางเพิ่มเอกสาร

- เก็บภาพรวมและวิธีเริ่มใช้งานแบบสั้นไว้ใน `README.md` ที่รากโปรเจกต์
- เพิ่มรายละเอียดในหมวดที่เกี่ยวข้อง: `dev/`, `design/`, `database/`, `academic/` หรือ `presentation/`
- เพิ่มลิงก์ในหน้ารวมนี้เมื่อมีเอกสารใหม่ และใช้ลิงก์แบบ relative เพื่อให้อ่านต่อได้จาก repository
- เมื่อเปลี่ยนคำสั่งหรือขั้นตอนใช้งาน ให้อัปเดตคู่มือที่เกี่ยวข้องพร้อมกัน
