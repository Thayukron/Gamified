ARCANA PROFILE

ระบบคัดกรองผู้เรียนผ่านเกม เพื่อสร้างไกด์การจัดการเรียนการสอนที่เหมาะกับผู้เรียนที่แตกต่างกัน

วิทยาลัยการอาชีพศรีสะเกษ
สังกัด สอศ.

1. ระบบนี้คืออะไร

เว็บแอปพลิเคชันที่ให้ผู้เรียนเล่น เกมผจญภัยแบบ Visual Novel ประมาณ 10–15 นาที ทุกการตัดสินใจในเกมถูกแปลงเป็น โปรไฟล์ผู้เรียน 3 ด้าน แล้วระบบประมวลเป็น ไกด์การจัดการเรียนการสอน ให้ครูแต่ละรายวิชาและกลุ่มเรียน — เกมเป็นเพียงเครื่องมือคัดกรอง เป้าหมายคือการสอนที่ตรงกับผู้เรียน

เล่นเกม➜โปรไฟล์ 3 ด้าน➜ไกด์การสอนรายวิชา➜จัดกลุ่ม/ซ่อมเสริม➜รายงาน ว.PA

2. ที่มาและความสำคัญ

  • ผู้เรียนแต่ละห้องแตกต่างกันทั้งวิธีเรียน ความสนใจ และแรงจูงใจ แต่ครูมีเวลาน้อยในการรู้จักผู้เรียนรายคน
  • แบบสอบถามแบบเดิมน่าเบื่อ ผู้เรียนมักตอบส่ง ๆ หรือตอบตามที่ “ควรเป็น” ข้อมูลจึงไม่สะท้อนตัวจริง
  • พ.ร.บ.การศึกษาแห่งชาติ 2542 ม.22, 24 และเกณฑ์ ว.PA ให้จัดการเรียนรู้ตามความแตกต่างระหว่างบุคคลโดยมีหลักฐานเชิงข้อมูล

3. วัตถุประสงค์

  1. เพื่อคัดกรองผู้เรียนรายบุคคลและรายห้อง ด้านสไตล์การเรียนรู้ ความสนใจอาชีพ และกรอบความคิด
  2. เพื่อสร้างแนวทางเลือกสื่อ วิธีสอน การซ่อมเสริม และการจัดกลุ่มที่เหมาะกับผู้เรียนแต่ละรายวิชาและแผนก
  3. เพื่อลดภาระครูในการจัดทำหลักฐานและรายงานผลการพัฒนางาน (ว.PA)

5. สิ่งที่ระบบทำได้

ผู้เรียน

  • เล่นเควสต์ มีตัวละคร มินิเกม
  • ได้การ์ด Archetype + โปรไฟล์
  • เล่นครั้งเดียว ใช้ได้ทุกวิชา

ครูผู้สอน

  • สร้างวิชา เลือกกลุ่มเรียนเอง
  • แดชบอร์ดห้อง + รายคน
  • ไกด์การสอนรายหน่วย (+AI)
  • จัดกลุ่ม · รายงาน ว.PA

ผู้ดูแลระบบ

  • นำเข้าข้อมูลจาก Excel / CSV
  • จัดการผู้ใช้ รีเซ็ตรหัสผ่าน
  • ตั้งค่า AI และข้อมูลสถานศึกษา

6. ประโยชน์ที่คาดว่าจะได้รับ

  • ผู้เรียน รู้จักจุดแข็งของตนเอง ได้เรียนด้วยวิธีที่หลากหลายและเหมาะสม
  • ครู รู้จักผู้เรียนตั้งแต่ต้นภาคเรียน ได้แนวทางสอนพร้อมใช้ มีหลักฐานประกอบ ว.PA
  • สถานศึกษา เห็นภาพรวมผู้เรียนรายแผนก ใช้วางแผนพัฒนาการสอนและงานแนะแนว

7. จุดเด่นของระบบ

  • ต้นทุนต่ำ ไม่เสียค่า AI ระหว่างเล่น · AI ใช้ API Key ของครูเอง เรียกเมื่อกดเท่านั้น
  • ปลอดภัยตาม PDPA ครูเห็นเฉพาะผู้เรียนในวิชาตน ไม่ส่งชื่อผู้เรียนให้ AI
  • ใช้งานง่าย เปิดผ่านเว็บได้ทั้งมือถือและคอมพิวเตอร์
